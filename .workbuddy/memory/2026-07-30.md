# 2026-07-30

- **LeaguePicker 联赛多选下拉无法滚动（H5 模式，21:21）**：用户指正代码在 `client/src`（Taro H5，`npm run build:h5`），不是 `server/static` 赔率台。根因两处叠加：
  1. `client/src/components/LeaguePicker/index.scss` 的 `.league-modal-list { overflow: hidden }` —— Taro `<ScrollView scrollY>` 在 **H5 模式**下渲染成普通 `<div>`，滚动完全靠该元素 overflow 实现；写 `overflow: hidden` 直接禁掉滚动。
  2. `index.tsx` 第 72 行列表高度上限锁死 `Math.min(leagues.length*56+10, 260)`px（约 4-5 个联赛），且 `.league-modal` 整体 `max-height: 340px` 偏矮。
  - 修复：`.league-modal-list` 改 `overflow-y: auto` + `-webkit-overflow-scrolling: touch`；`.league-modal` `max-height` 340→480；列表高度上限 260→420。已 `npm run build:h5` 编译通过。
  - ⚠️ **Taro H5 踩坑**：给 ScrollView 元素套 `overflow:hidden` 类会禁掉 H5 滚动；列表高度务必留足或用滚动区。
  - 注意：用户当前打开的 IDE 标签 `server/app/static/public/home.js/.css` 实际不存在（该 public 目录从未落库），属 IDE 缓存残留标签，勿被误导。
- **Taro dev server `Cannot GET /`（21:27）**：`client/config/dev.ts` 配的 `devServer.static.serveIndex: false` + `historyApiFallback.rewrites[].to: '/index.html'` 组合导致 webpack-dev-server 找不到内存里 HtmlWebpackPlugin 注入的 index.html（绝对路径不 resolve）。实测 `GET /` 与 `GET /index.html` 都返回 `Cannot GET /`。**修复**：把 `to` 改成 `'./index.html'`（相对路径，按 publicPath 解析内存里的 index.html）。改 webpack-dev-server 配置 **不会热重载**，需手动 Ctrl+C 重启 `npm run dev:h5`。访问 LAN IP（如 `192.168.1.4:10086`）的「不安全」是浏览器对内网 HTTP 的提示，与此 bug 无关。
- **MySQL (1129) Host blocked（21:30）**：uvicorn 启动后 cache_warmer / scheduled sync 报 `(pymysql.err.OperationalError) (1129, "Host '139.226.182.199' is blocked because of many connection errors; unblock with 'mysqladmin flush-hosts'")`。**根因**：本机公网 IP 被远程阿里云 MySQL(47.101.167.103) 封锁（max_connect_errors 累积连接失败，源于 7-27 之前的 Windows 驱动踩坑 WinError87/2003/SSL 失败遗留）。**诊断要点**：报错里的 `pymysql.err.OperationalError` 实为 **aiomysql 复用 PyMySQL 异常类**（aiomysql 基于 pymysql 的 asyncio 实现），cache_warmer 其实走 async_session_factory，并非 sync 连接——勿误判为 sync/pymysql 配置问题。**解封必须服务器侧**：阿里云 RDS 控制台重启实例 / DMS 执行 `FLUSH HOSTS;` / SSH 到 ECS 本地 socket 执行 `FLUSH HOSTS;`。**本机无法解封**（IP 已封连不上）。建议解封前先 Ctrl+C 停 uvicorn，避免解封瞬间被本机 reconnect 砸回重新被封；解封后重启 uvicorn 验证。
