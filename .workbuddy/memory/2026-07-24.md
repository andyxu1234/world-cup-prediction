## Kelly/概率算法修复（10:17~10:52）
- **问题**：`odds.py` 的 `dist_pct`（AI 概率分布）用纯投票占比（10/10=100%），导致全票时概率=100%、Kelly 爆表到 100%。

## 修复 PM 手动关联 Link 404（16:30）
- 问题：私密赔率台「PM 关联」Tab 手动关联弹窗点 Confirm Link 报 `Link failed: HTTP 404`。
- 根因：
  1. 前端 `api()` 只支持 GET（签名 `api(path, params)`），调用时第三个参数 `"PUT"` 被忽略，实际发了 GET 请求到只有 PUT 注册的后端路由。
  2. 弹窗要求输入 Highlightly 外部 `matches.id`（即本地 `matches.highlightly_id`），但后端原接口只按本地 `matches.id` 校验，输入外部大 ID 会报 `Match id=... not found`。
- 改动：
  - 前端 `server/app/static/odds.v15.js`：扩展 `api(path, params, method)`，默认 GET，支持传入 method；PM 关联 confirm 改为 `api("/polymarket/" + eventId + "/match", { highlightly_id: hlIdVal }, "PUT")`；unlink 调用原本就带 `"PUT"`，现在终于生效。
  - 后端 `server/app/api/v1/odds.py`：`/polymarket/{event_id}/match` PUT 接口新增 `highlightly_id` query 参数；优先用 `match_id`，否则按 `Match.highlightly_id == highlightly_id` 映射到本地 `match.id`；找不到返回 404 并带明确提示；解除关联逻辑不变。
  - 前端 `server/app/static/index.html`：弹窗 label 由 `MATCH ID` 改为 `HIGHLIGHTLY MATCH ID`，hint 改为说明后端会自动映射到本地 match。
- 注意：后端 Python 改动需重启 FastAPI；前端 `odds.v15.js` 和 `index.html` 原地改、版本号未动，Ctrl+Shift+R 强刷。lint 通过。
