## 修复：Windows 本地 FastAPI 连远程 MySQL 全程 500/WinError 87
- 现象：Swagger 调任何查库接口（含 `公共频道发帖`）报 `asyncmy OperationalError WinError 87`；改 aiomysql 后又先后报 `'dict' object has no attribute 'wrap_bio'`、再 `2003 Can't connect`。
- 诊断：`pymysql` 同步 + 裸 TCP 都正常（server 5.7.40-log，账号/网络没问题），问题纯在异步驱动在 Windows 的兼容性。
- 三处改动（已落地，跑通 `/api/v1/matches/stats` 返回真实数据）：
  1. `config.py`：win32 用 `mysql+aiomysql://`，否则 `mysql+asyncmy://`。
  2. `database.py`：`connect_args["ssl"]` 改传 `ssl.SSLContext` 对象（不再是 dict）。
  3. `main.py` 顶部：win32 设 `asyncio.WindowsSelectorEventLoopPolicy()`。
- 验证：`.venv\Scripts\python.exe` 跑临时脚本确认 aiomysql+SelectorEventLoop+SSLContext `select 1`=1；curl `GET /api/v1/matches/stats` 返回 200 + 真实数据。临时脚本 `_dbtest.py` 已删。
- 详细配方已更新 MEMORY.md「数据库/迁移」区块。
