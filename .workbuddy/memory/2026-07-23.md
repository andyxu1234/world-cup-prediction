- **后端**（`odds.py` 新增 `GET /api/v1/odds/polymarket/{event_id}/analysis`）：
  - 取 `match_id` 关联比赛的 `predictions`（按 `result` 投票算分布 `distribution_pct` + 平均置信度）+ `prediction_summaries` 文本；取 `polymarket_markets` 各腿 YES 价。
  - **EV 公式（已验证）**：`EV(Home YES) = AI_P(home) − price`；`EV(Home NO) = price − AI_P(home)`；ROI=EV/成本；**凯利** `f*(YES)=EV/(1−price)`，`f*(NO)=EV/price`（EV≤0 则 kelly=0/不计）。
  - 返回 `overround`(三腿 YES 价之和，越低越高效)、`bets`(逐腿 YES/NO 指标)、`best_bets`(EV>0 降序)；未关联比赛 → AI 占位提示，仅市场价。
- **前端**：`index.html` 新增 `#pmAnalysisModal`(宽弹窗 `pm-modal-wide`)；`odds.v15.js` 每行加「分析」按钮→`loadPMAnalysis`→`renderPMAnalysis` 渲染（头部/AI 分布条+summary/市场 chips+overround/逐腿对比表[正绿负红]/正 EV 建议+免责声明）；`odds.v15.css` 全量 `.pa-*` 样式。**对比表 `min-width:760px` + 外层 `overflow-x:auto` 横向滚动**（遵循用户"过宽提供滚动不裁切"硬偏好）。
- **注意**：新增路由需**重启后端**才生效（用户当时已有 server 在跑）。
