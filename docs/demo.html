Architecture

技术架构

现代化全栈技术栈，确保高性能与可扩展性

FRONTEND

  • Taro 4.1 跨端框架
  • React 18 + TypeScript
  • Zustand 状态管理
  • SCSS 模块化样式
  • 微信小程序原生 API

BACKEND

  • FastAPI + Uvicorn
  • SQLAlchemy 2.0 (Async)
  • MySQL 8.0 数据库
  • JWT 认证体系
  • APScheduler 定时任务

AI SERVICES

  • OfoxAI 统一网关
  • LangGraph 编排引擎
  • 10 个主流 LLM 接入
  • Prompt 模板管理
  • 智能输出解析器

INFRASTRUCTURE

  • Docker Compose 编排
  • Nginx 反向代理
  • Highlightly 数据源
  • Pillow 图片生成
  • Alembic 数据库迁移
