# 分享图优化说明

## 优化内容

### 1. 服务端分享卡片图片优化

#### 1.1 视觉设计改进
- **背景渐变**：从单一的绿色渐变改为蓝绿渐变，更符合世界杯主题
  - 顶部：蓝色 (#0d6efd)
  - 中间：绿色 (#10b981)
  - 底部：深绿色 (#059669)
- **卡片尺寸**：从 750×660 改为 750×1000，竖版更适合手机分享
- **字体大小调整**：增大关键文字，提升可读性
- **配色方案**：添加金色点缀色 (#fbbf24)，提升视觉层次

#### 1.2 内容布局优化
- **标题区**：添加 "⚽ 世界杯 AI 预测大赛" 标题，使用金色高亮
- **比赛信息**：保留国旗、队名、VS、时间等核心信息
- **AI预测区**：新增 AI 预测结果展示区域
  - 显示最多5个AI模型的预测
  - 每个预测显示：模型名 | 预测结果 | 比分
  - 预测结果使用金色高亮
- **底部区**：
  - 标语："AI 预测世界杯 · 谁才是最强预言家？"
  - 小程序码：居中显示，尺寸100×100

#### 1.3 小程序码修复
- **路径修复**：从 `server/avatars/mini.jpg` 改为 `avatars/mini.jpg`
- **位置优化**：从右下角移到居中位置，更显眼
- **占位优化**：如果加载失败，显示"扫码体验"占位框

### 2. 前端分享页面优化

#### 2.1 样式改进
- **背景渐变**：从绿渐变改为蓝绿渐变，与服务端保持一致
  ```scss
  background: linear-gradient(160deg, #0d6efd, #10b981, #059669);
  ```
- **阴影效果**：增强阴影，增加立体感
  ```scss
  box-shadow: 0 12px 40px rgba(13, 110, 253, 0.3);
  ```
- **文字效果**：
  - Logo文字改为金色，添加阴影
  - VS文字加大加粗，更醒目
  - 标语文字添加阴影效果
- **小程序码区域**：
  - 尺寸从100×100增加到110×110
  - 添加阴影效果
  - 圆角从14px增加到16px

#### 2.2 视觉层次
- **顶部**：标题区，金色Logo，吸引注意
- **中部**：比赛信息，白色文字，清晰展示
- **底部**：标语+小程序码，引导用户扫码

1. **服务端**：

2. **前端**：
   - `client/src/pages/share-card/index.scss` - 分享页面样式

## 技术细节

### 小程序码路径计算
```python
base_dir = os.path.dirname(os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
qr_path = os.path.join(base_dir, "avatars", "mini.jpg")
```

路径层级：
- `__file__` = `app/services/share_card.py`
- 3次 `dirname` 后 = `server` 目录
- 最终路径 = `server/avatars/mini.jpg` ✅

### 颜色方案
- 蓝色渐变起：(13, 110, 253) - #0d6efd
- 绿色中间：(16, 185, 129) - #10b981
- 绿色渐变止：(5, 150, 105) - #059669
- 金色点缀：(251, 191, 36) - #fbbf24
- 白色：(255, 255, 255)
- 暗白色：(210, 235, 225)
