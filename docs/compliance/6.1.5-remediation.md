# 微信小程序 6.1.5 违规整改记录（前端）

> 触发条款：《微信小程序运营规范》6.1.5 —— 包含赌博、竞猜和抽奖信息、外围彩票及提供彩票预测服务。
> 整改原则：**仅改前端**（后端部署在阿里云，用户明确要求不动），把「参与式竞猜」彻底下架，AI 内容转为只读分析展示，敏感词全面替换。

## 一、已下架的参与式 / 竞猜功能（核心违规点）

| 页面 | 改动 |
| --- | --- |
| `pages/match-detail` | 删除「投出你的预测」投票/下注区（主胜/平局/客胜 + 比分输入）、删除「观看视频解锁 AI 预测」广告解锁三态机；AI 结论改为中性标签（主队占优/势均力敌/客队占优），「AI 共识」→「AI 观点」「综合信心」→「模型信心」；正文与页脚加 AI 分析免责声明；信息流广告保留 |
| `pages/leaderboard` | 删除「人类排行」竞猜排行榜 tab 及整段渲染；清理无用 `UserAvatar`/`isValidImageUrl`/`topUsers`；分享文案去掉「预测之王」 |
| `pages/profile` | 删除「我的战绩」菜单入口与竞绩统计块（已预测/胜负正确/比分命中）；分享文案去「完成 X 场预测，快来参与」 |
| `pages/index` | 删除「人类预测总场次」统计与 click→人类排行；「人机对决」「智能预测」从副标题移除；「AI 共识」→「AI 观点」「查看预测」→「查看分析」；「AI预测总数」→「AI分析总数」 |
| `pages/vote-history` | **整页删除**（竞猜历史 + 命中率记录），并从 `app.config.ts` pages 移除 |

## 二、全局敏感词替换（预测→分析，去除投注/竞猜/盘口等）

- 小程序标题 `navigationBarTitleText`: `AI 预测世界杯` → `AI 足球分析`
- 分享文案统一为「AI 足球分析 · 多模型赛事解读」等中性表述
- `about` 页：去掉「人机对决/我的战绩/亲自下场预测/AI 预测世界杯」，改为「AI 足球分析平台」「数据视角读懂比赛」
- `disclaimer` 页：去除「投注/竞彩/彩票/赌博」措辞，改为「不构成任何投资或决策建议」「理性观赛」
- `contact` / `profile-setup` / `ai-detail`：去除「AI预测」「预测快乐」「开始预测」「预测失误」等，改为「AI 赛事分析」「理性观赛」「开始体验」「分析偏差」
- 品牌署名 `AI PREDICTOR` → `AI ANALYST`；标语 `预测快乐 · 理性观赛` → `理性观赛 · 享受足球`

## 三、仍保留的合法部分

- 10 个 AI 模型的**只读分析/观点**展示（AI 排行、AI 详情、比赛详情中的 AI 卡片）——定位为「AI 体育内容/数据」，不属于投注闭环。
- `match_odds` 等后端数据表未动（学术研究合法），但**前端不展示赔率数字与博彩公司 logo**。
