# 世界杯 AI 预测大赛 — 产品需求文档

## 1. 产品概述

### 1.1 产品定位
一款面向公众的微信小程序，让多个 AI 大模型同台竞技，预测 2026 FIFA 世界杯比赛结果。用户可以围观 AI 预测、参与投票、与 AI 一较高下，并通过社交分享扩大传播。

### 1.2 目标用户
- 对 AI 技术感兴趣的泛互联网用户
- 世界杯球迷
- 喜欢竞猜、排行类轻游戏的用户

### 1.3 核心价值
- **趣味性**：看 AI 在体育预测上"翻车"或"神预测"
- **社交性**：分享预测卡片、站队互动
- **话题性**：AI vs 人类、不同 AI 模型之间的对比

---

## 2. 功能需求

### 2.1 核心预测模块

#### 2.1.1 单场预测
每场比赛，各 AI 模型需输出：

| 预测项 | 说明 |
|--------|------|
| 胜负平 | 主胜 / 平局 / 客胜 |
| 比分预测（模式一） | 单个比分，如 2:1 |
| 比分预测（模式二） | 两个比分及各自概率，如 2:1 (60%)、1:1 (40%) |
| 预测分析 | 一段文字说明预测理由（50-150 字） |

#### 2.1.2 长期预测
赛前（或小组赛阶段），各 AI 模型需预测：
- 冠军
- 亚军
- 季军

### 2.2 排行榜模块

#### 2.2.1 AI 模型排行榜
- **胜负预测准确率**：正确 / 总场次
- **比分预测准确率**：完全命中 / 总场次
- **综合得分**：加权计算（胜负权重 + 比分权重）
- 支持按轮次筛选（小组赛 / 淘汰赛 / 全部）

#### 2.2.2 模型风格画像
基于历史预测数据，自动为每个模型生成标签：
- 保守派 / 激进派
- 强队粉 / 冷门猎手
- 大比分爱好者 / 小比分稳健型

### 2.3 用户参与模块

#### 2.3.1 投票预测
- 用户可以对每场比赛投票预测比分
- 无需登录，微信授权即可参与

#### 2.3.2 人机排行榜
- 用户群体平均正确率 vs 各 AI 模型
- 展示"人类代表队"的整体表现

#### 2.3.3 站队玩法
- 用户赛前选择支持某个 AI 模型
- 该模型的战绩即为用户的战绩
- 按站队结果展示用户排名

#### 2.3.4 信心指数
- 每场预测附带信心值（1-10 分）
- 事后统计：高信心场次的实际正确率（校准度）

### 2.4 AI 分析可视化模块

#### 2.4.1 预测对比
- 同一场比赛，各模型预测结果的对比视图
- 直观展示模型之间的分歧

#### 2.4.2 历史战绩热力图
- 每个模型按比赛轮次/对手强度的正确率热力图

#### 2.4.3 "被打脸"合集
- 自动汇总模型预测最离谱的场次
- 配上幽默文案，增强传播性
- 按"打脸指数"排序

### 2.5 分享模块

#### 2.5.1 预测分享卡片
- 生成精美的图片卡片，包含：
  - 比赛信息（对阵双方、时间）
  - AI 模型名称及预测结果
  - 产品二维码/小程序码
- 支持分享到微信聊天、朋友圈
- 风格要求：视觉吸引力强，适合传播

## 3. AI 模型支持

### 3.1 参与模型（MVP 阶段至少 3 个）
- Claude（Anthropic）
- GPT-4o（OpenAI）
- Gemini（Google）
- DeepSeek
- Qwen（通义千问）

### 3.2 调用方式
- 通过 **OpenRouter** 统一网关调用所有模型，只需申请一个 API Key
- OpenRouter 兼容 OpenAI API 格式，通过切换 `model` 参数即可调用不同模型
- 统一的 Prompt 模板，确保各模型收到相同的预测指令
- 预测结果需返回结构化 JSON

### 3.3 Prompt 设计原则
- 提供相同的比赛背景信息（历史交锋、近期状态、伤病等）
- 明确要求输出格式（胜负平 + 比分 + 分析文字）
- 不提供其他模型的预测结果（避免从众）

---

## 4. 数据需求

### 4.1 比赛数据
- 赛程信息（日期、时间、对阵双方、场地）
- 比赛结果（比分、胜负）
- 数据源：足球数据 API（如 API-Football）

### 4.2 预测数据
- 各模型的预测结果持久化存储
- 预测时间戳（确保在比赛开始前生成）

### 4.3 用户数据
- 微信 OpenID
- 站队选择
- 投票记录

---

## 5. 非功能需求

### 5.1 性能
- 页面加载时间 < 3 秒
- 预测结果缓存，避免重复调用 API

### 5.2 成本控制
- 每场比赛每个模型只调用一次 API，结果缓存
- 比赛开始后停止接受新的 AI 预测
- 预估 API 调用成本：48 队赛制约 104 场比赛 × 5 模型 = 520 次调用

### 5.3 平台
- 微信小程序（主要）
- 后续可考虑 Web 版

### 5.4 语言
- 中文

---
