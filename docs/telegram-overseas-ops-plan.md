# 海外版 Telegram 矩阵自动化运营方案（合规护栏版）

> 适用前提：目标用户**全部在海外**，不涉及中国大陆用户与境内支付。
> 定位：付费「AI 体育数据分析」交付（含模型输出、深度解读、历史胜率统计）。
> ⚠️ 本文为技术/运营架构草案，**不构成法律意见**。正式上线前请就目标市场与经营主体所在地咨询持证律师。

---

## 0. 先对齐的两件事（必读）

1. **你的物理位置仍是变量。** 即便用户全在海外，运营主体（你）位于中国大陆，PRC 对「从中国境内组织赌博相关经营活动」的认定通常不依赖用户国籍。建议严肃考虑：是否在目标市场当地或第三地（如合规司法辖区）设立经营主体 / 收款实体，把"运营决策地"和"你的居住地"在法律上分开。
2. **"海外"不是单一法域。** 美国（各州不同）、欧盟（各国不同）、中东、东南亚对"售卖体育赛事分析/建议""加密货币收款""赌博相关广告"的合规要求差异极大。上线前需先圈定**具体允许的 2–3 个目标市场**，逐一核对当地规则，不要"全球无差别投放"。

## 1. 角色分配（海外版）

| 角色 | 形态 | 职责 |
|---|---|---|
| 公开频道（1 个） | Telegram Channel | 公域引流、展示模型历史胜率、发布免费分析片段 |
| 付费群组 / 频道（N 个） | Telegram Group/Channel（按联赛或按会员档位分） | 核心交付区：完整模型输出 + 深度解读 |
| 机器人 A（内容推送官，自研 Python） | 经 BotFather 自建 Bot | 把 AI 算法结果按规则分发到频道与付费群 |
| 机器人 B（收银 / 发卡官，第三方系统） | 现成商业机器人 | 24h 接待、收 USDT/TRX/TON、自动发付费群进群链接、到期踢人 |
| 机器人 C（群管 / 防卫官，免费机器人） | @Rose / @Combot 等 | 防广告、验证码、敏感词、禁言 |

> 关键原则不变：**收银与群管用成熟第三方，自研只管"算法 + 内容推流"**。别自己造收银和风控。

## 2. 五大自动化闭环（重做成合规形态）

### 闭环 1 · 收款与进出群（机器人 B）
- 用户私聊机器人 B → `/start` 触发商品菜单（如：VIP 月卡）。
- 用户选加密货币付款 → 机器人生成**专属临时收款地址**（USDT-TRC20 / TON 等）。
- 链上监听确认（通常 2–5 分钟）→ 自动生成**一次性**付费群进群链接私发给用户。
- 到期前 1 天私聊提醒续费；到期未续费自动 `kick` 出群。
- ✅ 合规护栏：商品描述写"数据分析会员 / 去广告高级数据"，不写"稳赚 / 包中 / 倍投方案"。

### 闭环 2 · AI 分析内容分发（机器人 A，自研）
- AI 算法在 VPS 上 24h 运行，赛前 2h 或盘口异动时产出标准文本。
- **付费群**：推送完整模型输出（胜负倾向、概率分布、关键指标解读）。
- **公开频道**：只发"免费分析片段 + 历史胜率统计"，隐藏付费专属细节用于引流。
- ✅ 合规护栏：展示"**概率分布 / 模型输出**"，不使用"波胆必中 / 独赢稳胆"等承诺性措辞。

### 闭环 3 · 战绩与引流（机器人 A，自研）
- 赛后调用体育数据 API（如 API-Football）取真实赛果，比对模型输出。
- **如实**统计命中率，生成"本期模型表现"图文（含命中与未命中）。
- 公开频道转发，附"查看完整模型会员"入口。
- ✅ 合规护栏：**不夸大、不选择性只晒红单**（幸存者偏差 = 虚假宣传风险）。展示区间胜率而非"昨晚 8 连红"式诱导话术。

### 闭环 4 · 社群秩序（机器人 C）
- 新用户经付费链接进群 → 自动验证码（防广告爬虫）。
- 敏感词过滤（辱骂、竞品导流、违规盘口名等）→ 秒删 + 踢。
- 可选开启 Content Protection（防转发/截屏），保护付费内容不被倒卖。
- ✅ 说明：防偷单是"保护你的知识产权"，与赌博无关，合理。

### 闭环 5 · 算法服务健康（你侧）
- 监控 AI 算法服务、VPS、Bot Token 有效性；异常自动告警。
- 你每天唯一要盯的：后台流水 + 算法服务器状态。

## 3. 第一步：收银机器人选型（海外 + 加密货币）

| 方案 | 适用 | 优点 | 注意 |
|---|---|---|---|
| **@CryptoBot（Crypto Pay）** | Telegram 原生、USDT/TRX/TON | 与 TG 深度集成、自动化程度高、无需自建地址轮询 | 需核对其可服务地区与你的经营主体合规 |
| **InviteMember + 加密支付网关** | 想用订阅制管理会员生命周期 | 会员到期/续费管理成熟 | 原生加密支持看所接网关；确认能用 USDT |
| **@SmartPayBot 类** | 轻量、自助 | 上手快 | 逐个核对费率与地区限制 |
| **TON / TON Wallet** | 纯 TG 生态、低手续费 | 原生体验好 | 仅 TON 链，用户需持 TON |

> 选型建议：先圈定目标市场 → 确认该方案在你目标市场**可合法服务** → 用测试账号 0.01U 跑通"付款→链接→进群→模拟到期踢出"再放大。

## 4. 合规护栏清单（上线前逐条打勾）

- [ ] 圈定**具体允许的 2–3 个目标市场**，当地规则已核对

- [ ] 加密货币收款的税务 / 申报义务已咨询
- [ ] Bot Token、收款私钥、API Key 分开保管，不进代码仓库
- [ ] 用户协议 + 退款/争议处理规则明确

## 5. 落地顺序（一次只调通一个模块）

1. **Day 1 收银 + 进群闭环**：配机器人 B，自测 0.01U 走完"付款→链接→进群→到期踢出"。
2. **Day 2 推流脚本**：Python 定时脚本往测试群发消息，调好 Markdown/emoji 手机端排版。
3. **Day 3 合体 + 防卫**：接真实公开频道与付费群，配机器人 C，开 Content Protection。
4. **Day 4 战绩脚本**：接体育数据 API，跑通"赛果→比对→战报"且如实展示。
