# 分享卡片布局调整说明

## 调整内容

### 问题
国旗和国家名称出现重叠，影响视觉效果。

### 解决方案

#### 1. 国旗尺寸调整
- **之前**：150 × 100 像素
- **之后**：140 × 95 像素
- **原因**：稍微缩小国旗，避免占用过多空间

#### 2. 两旗间距调整
- **之前**：70 像素
- **之后**：80 像素
- **原因**：增大间距，让整体布局更舒展

#### 3. 队名与国旗间距调整（核心修复）
- **之前**：18 像素
- **之后**：30 像素
- **原因**：队名字体大小为 56px，18px 间距太小导致重叠，增加到 30px 确保清晰分离

#### 4. 时间与队名间距微调
- **之前**：60 像素
- **之后**：65 像素
- **原因**：配合队名间距调整，保持整体布局协调

## 布局参数总览

```
标题区（顶部）
├─ 标题：Y = 50
└─ 轮次：Y = 100

国旗区
├─ 国旗顶部：Y = 140
├─ 国旗尺寸：140 × 95
├─ 两旗间距：80px
└─ 队名位置：Y = 140 + 95 + 30 = 265  ← 关键调整

时间区
└─ 时间位置：Y = 265 + 65 = 330

AI预测区
└─ 开始位置：Y = 330 + 70 = 400
```

## 视觉效果改进

✅ 国旗和队名清晰分离，不再重叠
✅ 整体布局更加舒展、平衡
✅ 保持居中对齐的视觉美感
✅ 各元素间距协调统一
